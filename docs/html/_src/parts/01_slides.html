2 · הצוות לדוגמה

מהרצה ראשונה לתוצאה בדפדפן: חמש תחנות

  1. uv run agymesh up --with-master – נפתחים 4 חלונות; העובדים מצטרפים ומאזינים בעצמם.
  2. uv run agymesh status – כל שלושת העובדים במצב listening.
  3. בחלון המאסטר מקלידים מטרה בעברית; המאסטר מריץ dispatch-all עם הנושא.
  4. כל עובד מקבל משימה משלו (מ-task_template בקובץ הצוות), עובד במקביל ועונה. זמן טיפוסי: 20–40 שניות.
  5. נפתחת לשונית דפדפן עם שלושת החלקים: עברית מימין לשמאל, ציור ASCII משמאל לימין.

PS> uv run agymesh status art = listening poem = listening joke = listening

למה הצ׳אט באנגלית?

כמה סוכנים? בדיוק כמה שכתובים בקובץ הצוות

  1. מספר הסוכנים = מספר הרשומות במערך agents. מעתיקים את team.json של הדוגמה ועורכים.
  2. {topic} בתוך task_template מוחלף בנושא שהמאסטר שולח.
  3. שמות: אותיות קטנות, ספרות, - ו-_. התיקיות יחסיות לקובץ הצוות ונוצרות בשבילכם.
  4. מפעילים עם --team teams/review/team.json up --with-master. לברירת מחדל: "team_file" ב-config/setup.json. launch security perf פותח רק חלק מהסוכנים.
  5. גבול מעשי: כל חלון agy צורך כ-250 MB זיכרון ומכסת מודל – 3 עד 6 סוכנים למחשב זה נוח.
