הלוח בפעולה: ארבעה הייקו, שני עובדים, אפס התנגשויות

  1. המאסטר מוסיף ללוח עם todo-add: ארבעה --title, הייקו לכל עונה.
  2. dispatch אחד שולח ל-poem ול-joke: "Work the board".
  3. שניהם מבקשים באותו רגע – todo-claim אטומי, ולכן כל אחד מקבל משימה אחרת.
  4. כל עובד בלולאה: todo-claim ← עבודה ← todo-done, ושוב.
  5. לוח ריק ← NO_OPEN_TASK; העובד עונה עם המזהים שהשלים. מעקב: uv run agymesh todo-list.

5 · תפעול יומיומי

ארבעה סוכנים מפעילים יחד – ונשאר hub אחד בדיוק

  1. אם ה-hub לא רץ, פקודת הסוכן הראשונה (join, wait, send, reply, כתיבה ללוח) מפעילה אותו.
  2. כשכמה סוכנים עושים זאת יחד, כל אחד ממתין זמן אקראי של 0–3 שניות ובודק שוב.
  3. ה-hub תופס את הפורט באופן בלעדי – הראשון מצליח.
  4. השאר מגלים שה-hub כבר קיים ומתחברים אליו; ניסיון הפעלה כפול נכשל כי הפורט תפוס.
  5. התוצאה: גם בהפעלה בו-זמנית – hub אחד בדיוק (נבדק: 4 סוכנים בבת אחת ← hub אחד).
