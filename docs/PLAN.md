# PLAN — agymesh 1.11

Goal: a generic, reusable IPC mesh between interactive Antigravity CLI (`agy`) sessions, modelled
on Claude Code's session-to-session messaging (`cli:mesh-communication`). Communication must start
from inside the sessions, never from an external terminal. The `creative-trio` team (art, poem,
joke + master) serves as the example and as the integration test.

## 1. Architecture

```text
CLI (agymesh ...)  ──►  SDK: AgyMesh  (sdk.py = comms, sdk_admin.py = admin, sdk_base.py = wiring)
                         │
        ┌────────────────┼──────────────────────────┬──────────────────────────┐
  SessionService    Orchestrator / MeshChecker   InstructionWriter       HubLauncher / TerminalLauncher
  join/wait/reply   send/dispatch/ping/mesh      AGY.md from templates   detached hub / agy -i windows
        └──────────────┬─┘                                                       │
                 HubClient (gatekeeper: framing, timeouts, ack, rate-limit retry)
                       │  newline-delimited JSON over 127.0.0.1 TCP, one request per connection
                 HubServer ── HubRouter ── SessionRegistry · MailboxStore · RateGate · Journal
OriginGuard + ProcessTable (native process snapshot) stamp every message with the agy pid.
```

| Module | Responsibility |
|---|---|
| `protocol.py` | LineChannel framing (fixes glued/split TCP frames) |
| `hub/mailbox.py` | per-agent FIFO, max depth, TTL, overflow strategy, reply book, requeue |
| `hub/registry.py` | joined sessions, listening/busy/stale state (ListAgents analog) |
| `hub/gate.py` | per-sender token bucket from `rate_limits.json` |
| `hub/router.py` | pure op → handler logic, explicit errors (unknown peer, bad request) |
| `hub/server.py` | exclusive bind, accept timeout, ack-or-requeue delivery, journal |
| `client.py` | the single gateway to the hub; retries on `rate_limited` |
| `procs.py`, `procs_native.py` | process tree walk; refuses plain terminals |
| `session.py` | in-session primitives join / wait / reply |
| `orchestrate.py`, `meshcheck.py` | fan-out + gather; full who-reaches-whom matrix |
| `instructions.py`, `templates/*.md` | generated AGY.md for master and workers |
| `launcher.py` | detached hub start, `agy -i` windows (console or Windows Terminal) |
| `terminals.py` | running agy processes matched to mesh names |
| `render.py`, `cli/*` | plain-language output; argparse front-end |

## 4. Acceptance with live agy windows (manual)

1. `uv run agymesh up --with-master` → four agy windows; `uv run agymesh status` lists art, poem,
   joke as `listening`, each with an agy pid. `uv run agymesh terminals` matches pids to names.
2. In the master window: "check the mesh" → master runs `ping-all` → three `PONG`s "answered by
   agy pid …".
3. In the master window: "חלק את הנושא 'חורף ישראלי' לסוכנים" → one `dispatch-all` command;
   each worker window shows its own work; the master prints the merged result.
4. `mesh-check` → "Full mesh: all 12 links work".
5. If `wait` is cut off by the agy tool timeout, lower `session.wait_timeout_s`.
